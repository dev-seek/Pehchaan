API & Integration

Send call audio or a transcript and get back the facts, questions, evidence, and timings.

POST /v1/pehchaan/transcribe Open interactive API docs

Python

curl

Replace call.wav with your audio file. The Python example uses httpx. For a transcript, send the multipart text field in place of audio.

Response fields

baseline and asr
Plain and context-assisted transcripts, model names, and speech-to-text latency in milliseconds. With typed input, baseline is empty.
pehchaan.text_out and .entities
The resulting transcript and typed facts. Each fact includes its heard text, value, status, and source.
pehchaan.questions
The follow-up question for each detail that needs clarification.
entities[].reason, .candidates, and .admission
The evidence for a decision, the alternatives considered, and the rule applied. pehchaan.refused lists proposals the rules blocked.
pehchaan.timings_ms and .llm_calls
Pehchaan processing stage totals and the number of verifier decisions requested.
